# Lari — сайт

Сайт бренда мороженого **Lari** (Санкт-Петербург): мороженое без сахара и без лактозы, ботаническая линейка из 4 вкусов на двух основах.

## Что внутри
- `index.html` — лендинг (главная страница)
- `app/` — приложение предзаказа (выбор боксов, корзина, сбор партии)
- `assets/`, `fonts/` — изображения и шрифты

## Как открыть локально
Открыть `index.html` в браузере. Если шрифты не подгружаются по `file://`, запустить простой сервер из этой папки:

```
python3 -m http.server
```

и открыть http://localhost:8000

## Хостинг
